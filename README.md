# E-commerce Backend

Minimal instructions to run this **e-commerce backend API**  
(**FastAPI + PostgreSQL + Redis**) using **Docker** on any machine.

---

## 1. Prerequisites

- Install **Docker Desktop** (includes Docker Compose v2)
- Expose the following local ports as free:
  - **8000** (backend API)
  - **5432** (PostgreSQL)
  - **6379** (Redis)
